## 🎯 系统概述

### 项目背景
Storage Assistant是一个基于NFC技术的智能仓储管理应用，旨在解决传统仓储管理中物品识别困难、信息记录不便的问题。

### 系统目标
- **快速识别**：通过NFC技术实现物品的秒级识别
- **信息管理**：完整记录物品的基本信息和多媒体内容
- **便捷操作**：提供直观的用户界面和流畅的操作体验
- **跨平台支持**：支持Android和iOS平台

### 技术选型
| 技术领域 | 技术选型 | 选择理由 |
|---------|---------|---------|
| 前端框架 | Flutter | 跨平台开发，高性能渲染 |
| 数据库 | SQLite | 轻量级，本地存储，无需网络 |
| NFC支持 | nfc_manager | 功能完整，社区活跃 |
| 多媒体 | image_picker + video_player | 官方推荐，稳定性好 |

## 🏗️ 架构设计

### 整体架构
```
┌─────────────────────────────────────────────────────────────┐
│                       表示层 (Presentation)                   │
├─────────────────────────────────────────────────────────────┤
│   HomePage      ItemInfoPage      SettingsPage              │
│   (主页)         (物品详情)        (设置页面)                 │
└─────────────────────────────────────────────────────────────┘
                               │
┌─────────────────────────────────────────────────────────────┐
│                       业务层 (Business)                      │
├─────────────────────────────────────────────────────────────┤
│   NFCService     MediaService     DatabaseService           │
│   (NFC服务)      (媒体服务)       (数据库服务)                │
└─────────────────────────────────────────────────────────────┘
                               │
┌─────────────────────────────────────────────────────────────┐
│                       数据层 (Data)                         │
├─────────────────────────────────────────────────────────────┤
│   DataManager     Models          Database                  │
│   (数据管理)      (数据模型)       (数据库)                   │
└─────────────────────────────────────────────────────────────┘
```

### 架构原则
1. **分层架构**：清晰的职责分离
2. **依赖倒置**：高层模块不依赖低层模块
3. **单一职责**：每个模块只负责一个功能
4. **开闭原则**：对扩展开放，对修改关闭

## 🔧 模块设计

### 1. 表示层模块

#### HomePage模块
**职责**：
- 显示NFC标签识别状态
- 展示物品列表
- 提供添加物品入口

**核心状态**：
```dart
class HomePage extends StatefulWidget {
  @override
  _HomePageState createState() => _HomePageState();
}

class _HomePageState extends State<HomePage> {
  String? _currentTagId;
  List<ItemRecord> _items = [];
  bool _isLoading = false;
}
```

#### ItemInfoPage模块
**职责**：
- 显示物品详细信息
- 支持左右滑动导航
- 提供编辑和删除功能

**核心特性**：
- 手势检测系统
- 动画控制系统
- 多媒体展示系统

### 2. 业务层模块

#### NFCService模块
**职责**：
- 管理NFC会话
- 处理标签识别
- 防止系统应用干扰

**核心方法**：
```dart
class NFCService {
  Future<void> startSession({required Function(NfcTag) onTagDiscovered});
  Future<void> stopSession();
  Future<String?> getTagId(NfcTag tag);
}
```

#### MediaService模块
**职责**：
- 图片选择和处理
- 视频录制和播放
- 文件路径管理

### 3. 数据层模块

#### DataManager模块
**职责**：
- 提供统一的数据访问接口
- 管理数据库连接
- 处理数据转换

**核心接口**：
```dart
class DataManager {
  Future<List<ItemRecord>> getItemsByTag(int tagId);
  Future<int> addItem(ItemRecord item);
  Future<void> updateItem(ItemRecord item);
  Future<void> deleteItem(int itemId);
}
```

## 💾 数据设计

### 数据库表设计

#### items表（物品表）
| 字段名 | 类型 | 说明 | 约束 |
|-------|------|------|------|
| id | INTEGER | 主键 | PRIMARY KEY AUTOINCREMENT |
| name | TEXT | 物品名称 | NOT NULL |
| remark | TEXT | 备注信息 | NULLABLE |
| imagePath | TEXT | 图片路径 | NULLABLE |
| videoPath | TEXT | 视频路径 | NULLABLE |
| tagId | INTEGER | 关联标签ID | NOT NULL |
| createdAt | INTEGER | 创建时间 | NOT NULL |

#### 数据关系设计
```
NFC标签 (物理实体)
    │
    └── 物品记录 (1:N)
          ├── 图片文件 (0:1)
          └── 视频文件 (0:1)
```

### 数据流设计

#### 物品添加流程
```
用户操作 → 数据验证 → 文件保存 → 数据库写入 → 界面更新
```

#### 标签识别流程
```
NFC事件 → 标签解析 → 数据查询 → 界面展示
```

## 🔌 接口设计

### 内部接口

#### NFC服务接口
```dart
abstract class INFCService {
  Future<void> initialize();

  Future<void> stopTagReading();
  Stream<NfcTag> get tagStream;
}
```

#### 数据管理接口
```dart
abstract class IDataManager {
  Future<List<ItemRecord>> getItemsByTag(String tagId);
  Future<void> saveItem(ItemRecord item);
  Future<void> deleteItem(int itemId);
}
```

### 外部接口

#### 平台特定接口
- **Android NFC接口**：通过AndroidManifest配置
- **iOS NFC接口**：通过Info.plist配置
- **文件系统接口**：图片和视频的读写权限

## 🚀 部署设计

### 开发环境部署

#### 环境要求
- Flutter SDK 3.0+
- Android Studio / VS Code
- 物理设备（支持NFC）

#### 部署步骤
1. **环境配置**：安装Flutter SDK和开发工具
2. **依赖安装**：运行`flutter pub get`
3. **平台初始化**：运行`flutter create .`
4. **设备连接**：连接支持NFC的Android设备
5. **应用运行**：运行`flutter run`

### 生产环境部署

#### 构建配置
```bash
# Android构建
flutter build apk --release

# iOS构建（需要开发者账号）
flutter build ios --release
```

#### 发布流程
1. **代码审查**：确保代码质量和安全性
2. **测试验证**：功能测试和性能测试
3. **构建打包**：生成发布版本
4. **应用商店发布**：上传到应用商店
