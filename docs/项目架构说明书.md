# 项目架构说明书

## 一、系统概述

收纳小助手是一款基于Flutter开发的Android NFC标签管理应用，旨在帮助用户通过NFC标签管理物品存放信息。用户可以将物品名称存储到NFC标签中，并通过手机快速读取和管理这些信息。

## 二、技术架构

### 2.1 技术栈

- **框架**: Flutter 3.x
- **语言**: Dart
- **目标平台**: Android
- **NFC库**: nfc_manager ^3.3.0
- **最低Android版本**: API 21 (Android 5.0)

### 2.2 项目结构

```
lib/
├── main.dart                    # 应用入口
├── services/
│   └── nfc_service.dart         # NFC服务层
└── views/
    ├── home_page.dart           # 物品列表页面
    └── item_info_page.dart      # 物品信息页面
```

### 2.3 架构分层

#### 表示层 (Views)
- **home_page.dart**: 物品列表主页面
  - NFC标签读取和显示
  - 物品列表展示（支持序号显示）
  - 标签信息区域显示/隐藏切换
  - 存入物品和清空操作
  
- **item_info_page.dart**: 物品信息页面
  - 三种模式：新增物品、修改物品、取出物品
  - 物品名称输入（新增模式可编辑，其他模式只读）
  - 删除/取出操作
  - 写入NFC标签

#### 服务层 (Services)
- **nfc_service.dart**: NFC操作服务
  - NFC可用性检测
  - NFC会话管理
  - 标签读取（NDEF数据解析）
  - 标签写入（支持重试机制）
  - 标签格式化
  - 错误处理和状态管理

### 2.4 数据流

```
用户操作 → 页面组件 → NFC服务 → NFC硬件
                ↓
          状态更新 → 界面刷新
```

## 三、核心模块设计

### 3.1 NFC服务模块

#### 主要功能
- `isNfcAvailable()`: 检查设备NFC是否可用
- `startSession()`: 启动NFC扫描会话
- `stopSession()`: 停止NFC会话
- `readTag()`: 读取标签数据
- `writeTextToTag()`: 写入文本数据（带重试）
- `formatTagToNdef()`: 格式化标签为NDEF格式

#### 状态管理
- `_isSessionStarted`: 会话状态标志
- `_lastTagId`: 最近一次标签ID
- 定期标签存在性检测机制

### 3.2 页面模块

#### 物品列表页面 (HomePage)
- 状态管理：`ValueNotifier`用于NFC结果和状态
- 列表展示：`ListView.builder`实现
- 选中状态：`_selectedIndex`管理
- 标签信息显示：`_showTagInfo`控制

#### 物品信息页面 (ItemInfoPage)
- 模式枚举：`ItemInfoMode { add, edit, remove }`
- 操作状态：`_isOperating`防止重复操作
- 数据传递：通过构造函数参数传递

## 四、关键设计决策

### 4.1 NFC会话管理
- 使用`NfcManager`进行会话管理
- 会话启动后持续监听标签
- 支持错误提示和状态更新

### 4.2 数据存储格式
- 使用NDEF Text Record格式存储
- 每条物品记录占一行
- UTF-8编码

### 4.3 标签ID验证
- 记录当前标签ID
- 写入前验证标签是否更换
- 更换时提示用户确认

### 4.4 错误处理
- 写入重试机制（最多3次）
- 容量超限检测
- 标签类型识别
- 用户友好的错误提示

## 五、依赖关系

```
main.dart
    ↓
HomePage ← NfcService
    ↓
ItemInfoPage ← NfcService
```

## 六、扩展性考虑

### 6.1 功能扩展
- 可轻松添加新的物品属性
- 支持更多NFC标签类型
