## 🎯 应用概述

Storage Assistant是一款智能仓储管理应用，通过NFC技术帮助用户快速识别和管理存储物品。应用提供直观的界面和强大的功能，让仓储管理变得更加高效便捷。

### 主要特点
- 📱 支持Android和iOS平台
- 🔍 基于NFC的快速物品识别
- 📦 完整的物品管理功能
- 🎯 流畅的用户交互体验
- 📷 多媒体内容支持

## 🚀 快速开始

### 1. 应用安装
1. 下载并安装APK文件到支持NFC的Android设备
2. 确保设备已开启NFC功能
3. 启动应用，授予必要的权限

### 2. 首次使用
1. 将NFC标签靠近设备背面
2. 系统会自动识别标签并显示相关信息
3. 按照提示完成标签的初始化设置

## 📱 主要功能

### 1. NFC标签管理
**功能描述**：通过NFC技术识别和管理存储标签

**操作步骤**：
1. 打开应用，确保NFC功能已开启
2. 将NFC标签靠近设备背面
3. 系统自动读取标签信息
4. 查看或编辑标签关联的物品

**注意事项**：
- 确保标签与设备接触良好
- 避免同时靠近多个标签
- 如遇识别问题，重新靠近标签

### 2. 物品管理
**功能描述**：管理标签关联的物品信息

#### 添加物品
1. 在标签详情页面点击"添加物品"
2. 填写物品名称和备注
3. 选择或拍摄物品图片/视频
4. 点击"保存"完成添加

#### 查看物品
1. 在标签详情页面查看物品列表
2. 点击物品进入详情页面
3. 支持左右划动切换物品
4. 查看图片、视频等多媒体内容

#### 编辑物品
1. 在物品详情页面点击"修改"
2. 编辑物品信息
3. 更新图片或视频
4. 保存修改

#### 删除物品
1. 在物品详情页面点击"取出"
2. 确认删除操作
3. 物品将从系统中移除

### 3. 智能导航
**功能描述**：通过手势操作快速浏览物品

#### 左右划动功能
- **左划动**：切换到下一个物品
- **右划动**：切换到上一个物品
- **动画效果**：平滑的滑动过渡
- **位置指示**：显示当前物品位置（如"2/5"）

**操作技巧**：
- 快速轻扫可实现快速切换
- 缓慢滑动可欣赏动画效果
- 在物品列表边界会有视觉反馈

### 4. 多媒体管理
**功能描述**：管理物品相关的图片和视频

#### 图片管理
- **添加图片**：从相册选择或拍照
- **查看图片**：点击图片全屏查看
- **删除图片**：在编辑模式下删除

#### 视频管理
- **添加视频**：录制或选择视频
- **播放视频**：点击视频图标播放
- **全屏播放**：支持全屏视频播放
- **播放控制**：播放/暂停控制

## 🔧 详细操作指南

### 主页操作
1. **标签识别**：靠近NFC标签自动识别
2. **物品列表**：显示当前标签的所有物品
3. **添加物品**：点击"+"按钮添加新物品
4. **设置入口**：访问应用设置

### 物品详情页面
1. **基本信息**：查看物品名称和备注
2. **多媒体内容**：查看图片和视频
3. **操作按钮**：修改、取出、取消等操作
4. **导航指示**：显示当前位置和总数

### 滑动导航操作
1. **手势识别**：在物品详情页面水平滑动
2. **方向判断**：左滑下一个，右滑上一个
3. **动画反馈**：平滑的滑动过渡效果
4. **边界处理**：在列表边界提供视觉反馈

### 多媒体操作
1. **图片查看**：点击图片进入全屏模式
2. **视频播放**：点击视频图标开始播放
3. **播放控制**：点击屏幕显示控制按钮
4. **退出全屏**：点击返回按钮或屏幕

## ❓ 常见问题

### Q1: NFC标签无法识别怎么办？
**A:** 检查以下事项：
- 设备是否支持NFC功能
- NFC功能是否已开启
- 标签是否完好无损
- 标签与设备接触是否良好
- 重启应用或设备后重试

### Q2: 滑动切换不流畅怎么办？
**A:** 可能是以下原因：
- 设备性能较低，建议关闭其他应用
- 滑动速度过快，尝试缓慢滑动
- 应用版本问题，检查更新

### Q3: 图片或视频无法显示？
**A:** 检查以下事项：
- 存储权限是否已授予
- 文件是否损坏或丢失
- 存储空间是否充足
- 重新选择或拍摄媒体文件

### Q4: 如何备份数据？
**A:** 目前数据存储在设备本地，建议：
- 定期导出重要数据
- 考虑数据库备份方案
- 联系开发团队获取备份功能

### Q5: 应用闪退怎么办？
**A:** 尝试以下解决方案：
- 清除应用缓存和数据
- 重新安装应用
- 检查设备系统版本兼容性
- 联系技术支持
